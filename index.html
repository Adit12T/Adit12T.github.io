FlagshipPlatform · Model Context Protocol

A Spring Boot MCP server that gives Claude agents safe access to engineering tools

One Spring Boot service that exposes the tools both agents rely on through the Model Context Protocol.

The problem & scale

Agents need consistent, controlled access to engineering systems. Two agents had to share one tool layer instead of separate one-off integrations, with a clear limit on what each agent is allowed to call.

Architecture & execution

  • Designed and built the MCP server in Spring Boot so both agents share one tool layer.
  • Exposed four tool groups: EDI comparison, mapping and rule retrieval, Java source search, and log and doc lookup.
  • Built the MCP tool security: authentication, scoped access per tool, input validation and audit logging.
Agent→OAuth 2.1 · audience→Rate limit · Audit→Scoped tool→Domain code→Metrics

AI agent · Debugging

From Kibana error to verified fix: a Java debugging agent

An agent that takes a Java error from Kibana logs to a root cause, a recommended fix, a regression test, and a check that the error is gone.

Architecture & execution

  • Pulls errors and stack traces from Kibana and traces each one to the exact class and line.
  • Works out the root cause and recommends fixes inside IntelliJ IDEA Ultimate, where developers already work.
  • Closes the loop: drafts a regression test, then re-checks Kibana to confirm the error no longer appears.
Logs→class:line→Diagnose→Test→Verify

AI agent · Data reconciliation

An EDI reconciliation agent that finds what's missing between environments

An agent that compares EDI files across two environments and reports what is missing, duplicated or extra, with the likely cause.

Architecture & execution

  • Finds clients enabled in both environments, so every comparison is like-for-like.
  • Pulls each client's EDI files for a chosen line of business and compares them item by item.
  • Turns raw differences into a readable report: missing, duplicate and extra items, each with a likely cause.
Client lists→Enabled in both→Parse EDI→Compare→Report
