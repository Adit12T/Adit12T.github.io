AI agent · Debugging

From Kibana error to verified fix: a Java debugging agent

An agent that takes a Java error from Kibana logs to a root cause, a recommended fix, a regression test, and a check that the error is gone.

What I did

  • Built the log step: the agent pulls errors and stack traces from Kibana and traces each one to the exact class and line.
  • Had the agent work out the root cause and recommend fixes inside IntelliJ IDEA Ultimate, where developers already work.
  • Closed the loop: the agent drafts a regression test for the fix, then re-checks Kibana to confirm the error no longer appears.

Result: Built and in use by developers in internal environments. Every fix arrives with a test and a log re-check, not just a suggestion.

Platform · Model Context Protocol

A Spring Boot MCP server that gives Claude agents safe access to engineering tools

One Spring Boot service that exposes the tools both agents rely on through the Model Context Protocol.

What I did

  • Designed and built the MCP server in Spring Boot so both agents share one tool layer.
  • Exposed four tool groups: EDI comparison, mapping and rule retrieval, Java source search, and log and doc lookup.
  • Built the MCP tool security that controls what each agent is allowed to call.

Result: Built and in use internally. Two agents run on one secured tool layer instead of separate one-off integrations.

AI agent · Data reconciliation

An EDI reconciliation agent that finds what's missing between environments

An agent that compares EDI files across two environments and reports what is missing, duplicated or extra, with the likely cause.

What I did

  • Built the client-matching step: the agent finds clients enabled in both environments, so every comparison is like-for-like.
  • Pulled each client's EDI files for a chosen line of business and compared them item by item.
  • Turned raw differences into a readable report: missing, duplicate and extra items, each with a likely cause.

Result: Built and in use by developers in internal environments. A tedious manual file comparison became a single agent run with a report.
